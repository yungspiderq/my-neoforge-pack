# Chronicles: the new questbook

Minecraft 1.21.1 + FTB Quests + FTB XMod Compat + KubeJS.

## 14 illustrated chapters (253 quests)
- Awakening / Первая искра
- Homestead / Живая усадьба
- Mines / Под толщей камня
- Fields / Поле и очаг
- Builder / Город одного мастера
- Wilderness / Дикий компас
- Redstone / Пробуждение редстоуна
- Ocean / Глубинный атлас
- Alchemy / Тайная лаборатория
- Nether / Сквозь пламя
- End / За горизонтом
- Create: Foundations / Первые механизмы
- Create: Moving Cities / Живые конструкции
- Create: The Grand Factory / Великая фабрика

The 14 chapters use a 3-lane quest graph (instead of a 200-node line).
Every chapter has 18 mandatory objectives: briefing + 16 goals + final seal.
Wilderness contains a bonus 19th quest, a KubeJS stormwatch custom task.
The final seal depends on all 3 branches; bonus tasks never gate progression.
Every chapter has 4 custom themed PNG illustrations (14 headers + 14 strips with 3 placements) with localized titles.
All quests have RU/EN titles and descriptions. First-run welcome text is delivered by KubeJS.
Completing the chapter grants a collectible Chronicle Page, a balanced item/XP reward and a KubeJS custom reward.

## Files
- scripts/quest_chapters.json: authored items, chapter narratives and localized names.
- scripts/gen_quests.py: deterministic generator for SNBT + PNG art + KubeJS scripts.
- scripts/check_questbook.py: SNBT parser, dependencies, unique IDs, art and localization validation.
- scripts/pin_ftb_xmod.py: compatible XMod Compat pinned to 21.1.11 (later versions require newer FTB Library).
- config/ftbquests/quests/chapters/*.snbt: output generated by CI.
- config/ftbquests/quests/lang/en_us.snbt and ru_ru.snbt: localized output.
- kubejs/assets/kubejs/textures/gui/quests/: 14 original chapter artworks.
- kubejs/server_scripts/chronicles.js: FTB custom rewards and thunderstorm challenge.
- kubejs/startup_scripts/chronicle_items.js: Chronicle Page item registration.

## Rebuild
    python -m pip install pillow nbtlib
    python scripts/pin_ftb_xmod.py
    python scripts/gen_quests.py
    python scripts/check_questbook.py
    python scripts/pack.py refresh
    python scripts/pack.py validate

Run a Minecraft client to verify the quests display correctly after CI; this validates SNBT but does not simulate an actual client.
Use /ftbquests reload and /kubejs reload server-scripts after changing quests/scripts in development.
**Important**: when adding more content mods, make a new chapter for each actual gameplay mod; utility libraries (Architectury, Sodium etc) do not need their own chapters.
