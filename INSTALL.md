# Установка модпака — инструкция для игроков

Вам нужно сделать это **один раз**. Дальше моды будут обновляться сами:
при каждом запуске игры лаунчер сверяется с сервером и докачивает то,
что изменилось. Никаких «переустанови пак» и скачиваний архивов в дискорде.

**Что нужно:**
- Minecraft **1.21.1** + **NeoForge 21.1.252** (лаунчер скачает сам)
- Java 21 (лаунчер обычно ставит сам)
- Freesm Launcher, AstralRinth, Prism Launcher или MultiMC
- Ссылка на релиз: `https://github.com/<ник>/<репо>/releases`

---

## Вариант A — Freesm Launcher / Prism Launcher / MultiMC

Это лучший вариант: полный авто-синк без единой лишней кнопки.

1. Скачайте из релиза файл **`…-instance.zip`**.
2. В лаунчере: **Add instance** → **Import from zip** → выберите скачанный файл.
3. Запустите инстанс.
   - При первом запуске лаунчер скачает Minecraft 1.21.1, NeoForge и Java,
     затем `packwiz-installer` загрузит все моды (несколько минут).
   - В окне консоли будет видно строки `[packsync] …` и прогресс скачивания.
4. Готово. Дальше просто нажимайте **Play** — синхронизация происходит
   автоматически перед каждым запуском.

> **Как это работает:** в настройках инстанса прописана *Pre-Launch Command*.
> Перед стартом игры она запускает `packwiz-installer`, который читает
> `pack.toml` по HTTP, сверяет sha256-хэши и докачивает только изменения.
>
> Посмотреть/изменить: ПКМ по инстансу → **Edit** → **Settings** → **Custom commands**.

### Если хочется видеть процесс синхронизации
ПКМ по инстансу → **Edit** → **Settings** → **Console** → поставьте
«Show console while game is running».

## Вариант B — AstralRinth / Modrinth App

Эти лаунчеры не умеют импортировать MultiMC-инстанс, поэтому установка
состоит из двух шагов: импорт пака + включение автосинка.

### Шаг 1. Импорт

1. Скачайте из релиза файл **`.mrpack`**.
2. **Create profile** → **Import from file** (или просто перетащите файл в окно)
   → выберите `.mrpack`.
3. Дождитесь окончания установки и запустите профиль один раз — убедитесь,
   что игра стартует.

### Шаг 2. Включить автосинхронизацию

1. Откройте настройки профиля: **⚙ Options** (или ПКМ по профилю → **Options**).
2. Найдите раздел **Hooks** → поле **Pre-launch** / **Pre-launch command**.
3. Впишите туда **ровно** одну из строк (без кавычек, без лишних пробелов):

   **Windows**
   ```
   cmd /c packsync\sync.cmd
   ```

   **Linux / macOS**
   ```
   sh packsync/sync.sh
   ```

4. Сохраните и запустите профиль. В логе появятся строки `[packsync] …`.

> **Почему команда такая странная?**
> AstralRinth выполняет hook без shell: строка режется по пробелам и запускается
> напрямую, переменные вроде `$INST_DIR` не подставляются, а пути с пробелами
> ломаются. Поэтому вся логика (поиск Java, чтение адреса пака) спрятана
> в скриптах `packsync/sync.cmd` и `packsync/sync.sh`, а в hook остаётся
> короткая команда из трёх токенов.
>
> Рабочая папка hook-а — папка профиля (она же папка игры), поэтому
> относительный путь `packsync\sync.cmd` находится корректно.

### Если автосинк не заработал

Всё равно можно обновляться вручную: скачайте новый `.mrpack` из релизов и
импортируйте его заново — моды заменятся. Либо перейдите на Freesm/Prism (вариант A).

## Проверка, что всё работает

В папке игры должна появиться папка `mods/` с `.jar` файлами модов, а также:

```
<папка игры>/
├── mods/                       ← сами моды
├── config/                     ← общие конфиги
├── packsync/                   ← механизм синхронизации
│   ├── pack-url.txt            ← адрес пака
│   ├── packwiz-installer.jar
│   ├── sync.cmd / sync.sh
│   └── …
└── packwiz.json                ← что уже установлено (служебный файл)
```

Наличие `packwiz.json` — верный признак, что синхронизация отработала.

## Частые вопросы

**Нужно ли что-то делать, чтобы получить новый мод?**
Нет. Просто запустите игру. Если автор пака добавил мод — он скачается сам.

**А если я удалю мод из `mods/` руками?**
При следующем запуске синхронизация вернёт его обратно. Хотите отключить мод —
переименуйте файл, добавив `.disabled` (`jei.jar` → `jei.jar.disabled`),
и попросите автора пака сделать его опциональным.

**Сколько трафика?**
Докачивается только разница. Добавили один мод на 3 МБ — скачается 3 МБ.
Изменили конфиг на 2 КБ — скачается 2 КБ.

**Что-то сломалось после обновления.**
Сообщите автору пака и приложите лог из `<папка игры>/logs/latest.log`,
а также вывод консоли лаунчера (там видны строки `[packsync]`).
