# shaderpacks/

**Всё, что лежит здесь, скачивается игрокам в `.minecraft/shaderpacks/`.**

Кладите сюда `.zip` шейдерпаков (Complementary, BSL, SEUS и т. п.) — они
разойдутся всем игрокам вместе с модами.

Шейдер-моды (Iris / Embeddium++ / Oculus) добавляются отдельно, как обычные моды:

```bash
python scripts/pw.py add oculus
python scripts/pw.py add embeddium
```

## Важный нюанс с `side`

Шейдерпаки нужны только на клиенте. Если не хотите, чтобы они попадали
на сервер, добавьте их не файлом, а через Modrinth-метаданные с `side = "client"`,
либо вручную поставьте в `index.toml` нужное значение в соответствующем
`mods/*.pw.toml`:

```toml
side = "client"
```

> ⚠️ Шейдерпаки тяжёлые (20–100 МБ). Git-репозиторий с ними быстро разрастается.
> Для больших паков лучше включить Git LFS или выкладывать архивы в
> GitHub Releases и подключать их через `pw.py add-url`.
