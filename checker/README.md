# checker/ — окно «а моды-то скачались?»

`CheckMods.ps1` + `CheckMods.bat` — диагностическое окно на чистом
PowerShell + WinForms. **Ноль зависимостей**: работает на любой Windows 10/11
из коробки, ничего устанавливать не нужно.

Игроку достаточно скачать `CheckMods.bat` и дважды кликнуть.

---

## Что показывает

| Колонка | Смысл |
|---|---|
| Мод / файл | имя из `mods/*.pw.toml` (или путь для конфигов/ресурспаков) |
| Ожидаемый файл | какое имя файла требует пак |
| На диске | размер + результат проверки хэша |
| Статус | `НА МЕСТЕ` · `ОТСУТСТВУЕТ` · `ПОВРЕЖДЁН` · `ОТКЛЮЧЁН` · `ЛИШНИЙ` · `СИНК НЕ ШЁЛ` |

Статусы и что они значат:

- **НА МЕСТЕ** — файл есть и его sha1/sha256 совпал с заявленным. Именно это
  проверяет `packwiz-installer`, так что совпадение хэша = мод установится.
- **ОТСУТСТВУЕТ** — файла нет. Либо синк не запускался, либо оборвался.
- **ПОВРЕЖДЁН** — файл есть, но хэш не сошёлся (недокачался, побился диск,
  антивирус покусал). Лечится удалением файла и повторным запуском.
- **ОТКЛЮЧЁН** — рядом лежит `<имя>.disabled`. Так игрок сам выключил мод;
  `packwiz-installer` такие не трогает.
- **ЛИШНИЙ** — файл в `mods/`, которого нет в паке. Устанавливать его никто не
  просил, и удалять синхронизатор его не будет (не его ведомство).
- **СИНК НЕ ШЁЛ** — в папке игры нет `packwiz.json`. Значит `packwiz-installer`
  ни разу не отработал до конца — почти всегда это непрописанный hook.

Дополнительно в нижнем окне — лог: адрес пака, версия Minecraft и загрузчика,
результат сверки sha256 у `index.toml`, возраст `packwiz.json`.

## Кнопки

| Кнопка | Действие |
|---|---|
| **Проверить** | заново опросить сервер и сверить с диском |
| **Синхронизировать** | запустить `packsync\sync.cmd` и показать его вывод, затем перепроверить |
| **Показывать прогресс** | создаёт/удаляет `packsync\SHOW_GUI`. С ним синхронизация идёт **с видимым окном** `packwiz-installer` вместо тихого режима — главный инструмент, когда «непонятно, качается или нет» |
| **Открыть mods/** | проводник в папку с модами |
| **Открыть sync.log** | блокнот с логом синхронизации |
| **Обзор…** | выбрать папку игры вручную |

## Автопоиск папки игры

Окно само перебирает известные расположения и показывает только те, где есть
`packsync/` (то есть где пак реально установлен):

| Лаунчер | Путь |
|---|---|
| AstralRinth | `%APPDATA%\AstralRinthApp\profiles\<имя>` |
| Modrinth App | `%APPDATA%\ModrinthApp\profiles\<имя>` |
| Freesm Launcher | `%APPDATA%\FreesmLauncher\instances\<имя>\.minecraft` |
| Prism Launcher | `%APPDATA%\PrismLauncher\instances\<имя>\.minecraft` |
| MultiMC | `%APPDATA%\MultiMC\instances\<имя>\.minecraft` |
| Ванильный | `%APPDATA%\.minecraft` |

Разница принципиальная: у Theseus-лаунчеров (AstralRinth, Modrinth App) папка
профиля **и есть** папка игры, а у Prism-семейства игра лежит в подпапке
`.minecraft` — поэтому для них путь достраивается.

Адрес пака берётся из `<папка игры>\packsync\pack-url.txt`, так что окно всегда
проверяет против того сервера, на который настроен этот инстанс.

## Запуск

```powershell
# двойной клик по CheckMods.bat — или:
powershell -ExecutionPolicy Bypass -File CheckMods.ps1

# конкретная папка игры
powershell -ExecutionPolicy Bypass -File CheckMods.ps1 -GameDir "$env:APPDATA\AstralRinthApp\profiles\MyPack"

# другой пак
powershell -ExecutionPolicy Bypass -File CheckMods.ps1 -BaseUrl https://user.github.io/repo
```

Флаг `-STA` в обёртке `CheckMods.bat` обязателен: WinForms не работает в
single-threaded apartment по умолчанию в некоторых конфигурациях PowerShell.

## То же самое без Windows

`scripts/verify.py --game-dir` делает идентичную проверку кроссплатформенно
и годится для CI:

```bash
python scripts/verify.py --game-dir "$HOME/.local/share/astralrinth/profiles/MyPack"
```

Он дополнительно проверяет доступность `latest/instance.zip` и `latest/pack.mrpack`
и корректность `PreLaunchCommand` внутри них. Код возврата ненулевой при любом
провале — удобно вешать в CI.

---

## Границы

Окно **не запускает игру и не трогает аккаунты** — это чистая диагностика.
Запуск по-прежнему делает лаунчер (Freesm / AstralRinth / Prism), в котором
уже настроена авторизация.
