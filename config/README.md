# config/

**Всё, что лежит в этой папке, автоматически скачивается игрокам в `.minecraft/config/`.**

Просто положите сюда файлы конфигов из своей рабочей папки игры — они попадут
в `index.toml` при следующем `refresh` и разойдутся всем при запуске.

## Что синхронизировать, а что нет

| Синхронизируем | НЕ синхронизируем |
|---|---|
| `config/*.toml` — общие настройки модов | Личные настройки интерфейса |
| `config/<mod>/` — папки модов с общими конфигами | `options.txt` целиком (лучше через `preserve`) |
| серверные/клиентские правила, кастомные рецепты | Логи, кэш, миры |

## Как не затирать личные настройки игрока

В `index.toml` у файла можно поставить флаг `preserve = true` — тогда
packwiz-installer запишет файл **только если его ещё нет** и никогда не
перезапишет изменённый:

```toml
[[files]]
file = "options.txt"
hash = "..."
preserve = true
```

Скрипт `pw.py refresh` сохраняет этот флаг между пересборками.
В официальном packwiz флаг ставится командой:

```bash
packwiz manual add options.txt --preserve
```
